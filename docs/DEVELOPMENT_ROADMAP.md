# LifeHub — Development Roadmap (16 тижнів, 112 задач)

Статус: Documentation First, версія 1.0 від 2026-11-23.
Пов'язані документи: [MVP_SCOPE.md](MVP_SCOPE.md), [TECHNICAL_PLAN.md](TECHNICAL_PLAN.md), [USER_FLOWS.md](USER_FLOWS.md).

## Як користуватися планом

- Підготовчі етапи Documentation First (цей набір документів) і Design First ([DESIGN.md](DESIGN.md) + макети в `docs/design/project/`) **не входять** у 112 днів. День 1 — початок технічної підготовки.
- Детальні макети модулів, яких немає в Design First (Travel, Pantry, регулярні платежі, AI), готуються в підсумковий день тижня перед їхнім початком (дні 70, 84, 91, 105).
- Один день = одна невелика задача з чіткими межами. Орієнтир — до 10 хвилин активної участі користувача (поставити задачу, переглянути результат, перевірити). Якщо задача виявилася більшою — розбити на частини й зсунути решту плану, а не роздувати день.
- **День 7 кожного тижня** — перевірка якості, короткий підсумок і планування наступного тижня (оновити цей файл: позначки виконання, перенесення).
- Колонка «Залежить від» — номери днів, які мають бути готові раніше.
- Типи робіт чергуються: функціонал, UI, бізнес-логіка, тести, рефакторинг, документація, перевірка якості.
- Стандартна перевірка для кожного дня, окрім указаної: `lint`, `typecheck` і `test` проходять.
- Позначки пріоритету: P0 — MVP, P1 — LifeHub 1.0.
